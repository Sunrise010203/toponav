# TopoNav：先验拓扑视觉导航

基于先验道路拓扑和四向 RGB 图像，研究道路结构识别、定位、路径规划与连续导航。
当前是**研究与受限仿真原型**，尚未完成完整连续导航和实车验收。

## 目前已做到

- **拓扑规划与离散导航**：统一地图与场景格式，实现地图校验、候选定位、路径规划、封路重规划及异常停止。
- **视觉感知与证据提取**：已有冻结的四向 RGB 道路结构模型、模拟数据集和评估工具；实现声明标定与场景条件下的视觉运动、通道及前方几何证据提取。
- **受限连续控制**：实现左右 90° 转弯、T 形路口选向、阻挡等待、多节点衔接与参考图像节点确认，已有受限仿真验证；不代表普通直行已通过验收。
- **仿真与工程接入**：已有 PyBullet 可视化、Gazebo 相机与轮驱接入，以及 ROS2 桥接和受限仿真联调实现。
- **执行保护与审计**：实现输入故障拒绝、反馈绑定、执行超时、租约联锁、零速停车及日志审计；这些机制不等于实车安全认证。
- **实验与复现工具**：已有感知/导航对照、消融、图像与决策回放、回归审计和性能分析工具，保留现有模型、配置与实验报告。

## 还需要做到

1. **稳定完成直行闭环（S2）**：改善普通走廊、横向偏移和组合偏差下的完成率，解决重复纹理启动缺口，补足近场自由空间与制动证据。**目前 S2 未通过。**
2. **完成统一安全验收（S6）**：完成独立评估，统一核对相机/通信故障、制动、停稳与恢复行为。**目前 S6 未完成。**
3. **达到实时性目标**：在不降低证据精度和安全门槛的前提下优化视觉匹配与控制链路。**目前尚未达到 10Hz。**
4. **扩大适用范围**：验证更多材质、纹理、遮挡和标定变化，完善歧义拒识与重定位，避免把特定场景效果当成通用能力。
5. **补齐可复现验证**：从真实归档恢复缺失的历史工件，处理历史测试导入冲突，恢复完整回归与干净环境复现。
6. **推进实际部署**：完成完整任务链路的 ROS2 集成与端侧部署，再开展真实相机、驱动器超时制动及实车测试。
