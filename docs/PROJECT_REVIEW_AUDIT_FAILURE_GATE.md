## 问题与修改

第二十九批新增退出后首故障补充文件，但原`summarize_audit()`未读取它。修改前反例使用实际旧摘要和完整、末态绑定的合法审计，旁边已有`flush_ack_timeout`诊断，仍报告`audit_complete=true`、`fault_latched=false`。

本批将补充文件作为只可否决的门控：合法故障、坏格式、过大、不可读、符号链接或非普通文件均阻止完成；无补充文件沿用原门槛，不能证明所有故障都成功保存。保留原审计错误优先级，`terminal_status_bound`只表示结构绑定，不代表完成。

最多读取1025字节，允许的完整文件上限1024字节；严格验证版本、10种原因、0..64的pending和errno类型/范围，拒绝重复键及额外字段。只返回固定状态和合法小摘要，不复制无效输入。使用`O_NONBLOCK|O_NOFOLLOW`，不读取FIFO/目录、不跟随链接，关闭文件描述符。

读取仅发生在退出后的原摘要路径。普通文件/网络存储的操作系统I/O仍可能阻塞；这不是硬实时或全进程内存/磁盘有界保证。原执行日志解析总量尚未限制，补充文件也不是来源认证、物理停车或持久化保证。
