# 成对描述子：精确局部排除几何

2026-11-04：已保留默认接入。这是证据计算的等价优化，不是直行策略或安全验收。

## 实现边界

- [配对入口](/home/sunrise/toponav_project/roadvision/paired_descriptor_checks.py)
  仅在构造每个搜索对象时准备几何，并替换原排除圆的距离表达式。
- [LocalExclusion](/home/sunrise/toponav_project/roadvision/local_exclusion_population.py)
  先验证静态网格为有界、二维、同形、整数单位规则网格。
  半径平方为121、端点为有界float64二元坐标时，完整bool图先填True，
  仅在floor端点周围±12的保守窗口中执行原减/平方/加/比较。
  半径11的圆完全落在该窗口内；窗口最多25×25=625个距离位置，
  典型118×118图原本为13924个位置。不符合条件时走原全图表达式。
- 网格引用在这个搜索对象生命周期内必须不变。没有持久bitmap/分数缓冲，
  每次返回独立完整掩码；没有改变支持掩码AND、finite过滤、count/max、
  角色区分或每轨迹finally清理。
- **没有缩小模板匹配或竞争搜索范围**，没有修改数值归约、H/I、求逆、
  原生/整流/自定义过滤器路径，也没有接回旧patch/NCC、scratch/1D候选。
