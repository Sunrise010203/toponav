# 直行：描述子搜索总体的精确去重

本轮是实现等价性优化，不是新直行策略。候选/最终是否接入及全部测量见
[本轮报告](/home/sunrise/toponav_project/reports/straight-paired-populations-20261103/REPORT.md)。

## 复用条件

H/I 仍独立执行训练单应拟合、画布准备、patch/补边检查、NCC、阈值判定、
原因生成、保留轨迹/划分以及模型拟合。只有画布 dtype/shape/每个像素相同，
才沿用原来的同角色/同模板精确字节原始分数共享。

在该提供器内，排除总体再按端点 dtype/shape/精确字节、坐标形状、排除半径、
**腐蚀后支持范围**区分。支持范围只在本次区域初始化时精确比较；全 true
支持与 H 无掩码在数学和逐元素布尔选择上完全一致，因而可共用总体。
支持不同或端点不同就独立计算，既不把 H 的无掩码范围套给 I，也不把 I
的补边拒绝套给 H。

每个总体分别按逻辑角色与原始分数**生成令牌**保存 `(最大值, 有限有效数)`。
令牌仅在同角色/同模板原始缓存命中时相同；模板不同时，即使底层返回同一
可复用数组对象也必须重新归约。缓存不持有被替换的分数图。
`count_nonzero(bool)` 与原布尔求和的整数计数一致；最大值仍对原顺序的
`score[valid]` 执行原 NumPy 最大值归约。H 只取标量，I 仍取得自己的计数。

## 边界

- 完整画布匹配不减少搜索范围。相同 H/I 仍为每轨迹 8 次逻辑检查、4 次实际
  `matchTemplate`；模板/画布不同则仍独立匹配，跨角色不合并。
- 每提供器至多两份原始角色图、两个总体，每总体至多两个归约结果。
- 总体/分数/归约在每轨迹 `finally` 清除，异常亦清除。不跨轨迹、区域、帧
  或控制器使用；不向证据返回数组，不做异步/全局缓存。
- 本次区域准备好的支持范围只读；这些私有搜索器仅同步、非重入使用。
- 整流、非原过滤器和非原 H 搜索策略仍在计算证据前走原独立入口。
- 不改变权限、净空、模型、标定、相机、速度、制动/恢复预算或 0.8s/0.4s 门控。
