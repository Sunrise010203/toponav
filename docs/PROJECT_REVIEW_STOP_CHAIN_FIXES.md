日期：2026-10-29（Asia/Shanghai）。本批由纯接口回归推进到实际ROS2进程/DDS传输及PyBullet轮电机、120Hz物理轨迹检查。使用已暴露的旧参考地图场景，**不是新的正式S7/S2/S6、Gazebo、17类模型或实车验收**。

## 修复范围

### 执行器守卫：协议数值与无新帧中止

修改`ros2_ws/src/toponav_bridge/toponav_bridge/protocol.py`：

- 原`number()`对合法JSON整数`10**400`调用`math.isfinite`时抛`OverflowError`。一个已持有非零速度的MotorGate收到这种坏命令/时钟后，可能未锁存，内部仍保留旧速度。现在有限性谓词安全返回False，命令、事件、相机租约、时钟及配置沿原拒绝分支处理；不裁剪/转换数值、不放宽速度范围。
- 原代码在识别`aborted`零速命令之前要求存在新帧租约，违背“停车不需要新相机帧”的接口说明。现在仅零速中止可免除新帧绑定；仍必须通过完整命令校验、会话、序号、仿真时间及已有租约到期检查。普通零速、到达声明或非零运动不能借此获得免绑定权限，中止不续租、不授权运动。

ROS节点/物理执行器源码`nodes.py`未改，原0.6秒导航超时、0.8秒轮控租约、速度/制动限制不改。

### 回放与审计：精确识别必要证据，而非调整阈值

修改`ros2_ws/src/toponav_bridge/toponav_bridge/runner.py`：

1. **恢复挂起进程后多一张在途旧图**：原回放将所有终态图像数量写死为3。本批实际收到1张已经在途的旧图加3张正式停车后探测图，导致“终态图像4张”被误报为探测失败。现在有相机公开清单时，将所有收到的图像逐项绑定到清单身份、时间和像素哈希；必须恰好声明并实际收到3张非抑制探测图，每张只计一次，重复/缺失/身份或像素不符仍拒绝。额外在途终态图单独记账，不替代任何必要探测图。世界记录的探测身份还须与公开清单完全一致。
2. **两种租约的到期次序**：原挂起审计只看最新待处理相机帧的期限，漏掉上一条已接受速度的独立持有期限。本批旧速度租约早约15ms到期，停车比新帧期限早约11ms，原审计误报。现在以`min(待处理帧期限, 最后实际接受命令收据时刻+0.8秒)`检查；已拒绝/锁存后消息不能刷新期限。收据在accept之后采样，保留原-0.01秒记录容差及+0.20秒轮询预算，不扩大时限；也拒绝租约配置被改成其他值。

没有相机清单的旧控制器单测夹具仍沿用原“恰好3张终态图”的规则，不将它当成完整相机/DDS审计。历史冻结代码、套件、报告和哈希均未更新。

## 实际ROS2 / DDS / 物理诊断

`run_diagnostics.py`串行执行六种条件，使用真实ROS2 Humble进程与Fast DDS；world独占轮电机和事后物理真值，navigation只读取公开任务/参考RGB、相机和控制话题。实际导航仍是原参考地图RGB几何控制器，**没有调用17类冻结分类模型**。

| 条件 | 实际结果/执行器锁存原因 |
| --- | --- |
| 相机断流 | `remote_abort`，停止，无恢复运动 |
| 反馈丢失 | `remote_abort`，导航反馈超时停止 |
| 导航进程SIGSTOP | `command_lease_expired`，独立执行器租约停车后SIGCONT |
| 感知后端异常 | 在实际analyze_corner_rgb调用处注入RuntimeError，`remote_abort`到达执行器 |
| 超大数值命令 | 额外DDS进程发布合法JSON中的巨大整数，`invalid_command_envelope`并实际施加零速 |
| 正常参考路线 | 两条连续边完成，`remote_visual_stop`，独立节点确认保留 |

每组保留独立world/navigation/feedback进程PID、接收/实际施加命令、终态探测、相机图像和完整120Hz轨迹。所有运行均无墙接触，最终线速低于0.01m/s、角速低于0.02rad/s；重算全部制动片段均满足原0.30秒/0.05米要求，本次最大片段约0.167仿真秒、0.01224米。SIGSTOP条件按更早实际期限的轮询记录延迟约0.004秒；不是硬实时或实车停车保证。
