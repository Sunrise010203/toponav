# 第十三批：Gazebo独立执行端0.8秒租约

日期：2026-10-30。针对P0：导航主循环/GIL/步进助手阻塞时不能独立请求零速。
**本批完成Gazebo软件进程隔离，不是底盘固件、硬实时调度或实车安全认证。**

## 修改前证据

第十二批最终源码的真实SIGSTOP助手实验中，从故障钩子到主进程首次零速请求约30.030墙钟秒。
本批`baseline-reference.json`只读引用该原始运行/注入/冻结清单，并核对其runner哈希等于本批修改前快照。
这是零速请求延迟的已有反例，**不是与新物理轨迹逐帧相同的性能对照**；不覆盖或重跑旧证据。

## 修改内容

新增`simulation/gazebo_actuator.py`：

- **独立进程、唯一速度发布者。** 导航进程不再直接发布`/toponav/cmd_vel`；仅通过私有Unix
  SOCK_SEQPACKET管道发送一次完整命令。模型推理、导航GIL、相机等待和同步步进均不在执行进程内。
- **固定0.8秒、原绝对到期时间。** 使用主MotorGate接受命令时已有的steady时钟期限，
  到达执行端时消耗的传输/排队时间不会重置租约。不用仿真时间代替墙钟，不发续租心跳。
  到期后锁存零速并重复发布；新的帧、恢复的导航循环或迟到回复都不能重新授权运动。
- **独立校验。** 复用未改的MotorGate/命令契约，再校验会话、传输顺序、绝对时间、帧身份/采集时间去重。
  过期、未来、延长租约、重复帧、乱序和超限速度均失败归零。只为浮点计算允许纳秒以下比较误差，
  实际期限仍夹紧到`issued+.8`，不提供过期宽限。
- **失联停车。** 管道EOF立即锁存零速；主进程被SIGSTOP或不再发送命令时独立按原期限停车。
  执行进程在对端消失后，只要Gazebo速度订阅者仍连接就持续发布零速，不依赖导航进程清理。
- **明确区分启动零速与停止。** GUI待启动时的idle只维持零速，不授予/刷新租约；运动后的idle不能续租。
  紧急stop不要求新图像，且锁存后不能重启。正常关闭在自有Gazebo世界停止后回收自有执行进程。
- **不伪造停车反馈。** ACK仅表示执行进程完成了发布调用，不代表Gazebo接收、车轮响应或已停稳。
  新`audit/actuator.jsonl`记录独立时钟/期限/输出/锁存原因；结果`actuator_watchdog`单列证据。
  看门狗故障锁存后即使控制器声称visual_stop也不能将任务标为完成。

原0.8秒MotorGate、0.15m/s/0.30rad/s命令限速、静止/几何/节点门槛、模型、地图与相机均未修改。
新增执行模块和原协议源码纳入每次运行冻结清单。原30秒助手回复/物理时钟等待未修改；
主循环仍可能晚发现故障，但它已不再负责租约到期时的独立零速发布。

`native_watchdog_checks.py`实际运行原Gazebo/DART/Ogre2与原L型RGB控制器：

1. 在首次运动前，启动独立原生命令/位姿/时钟观察者和独立步进助手。
2. 已经有真实运动和新命令后，分别对自有步进助手SIGSTOP、对导航进程本身SIGSTOP、断开命令管道。
3. 导航无法推进时，由独立测试端继续按12步/0.1墙钟秒推进**原世界**约2.2秒，
   不是用暂停的物理世界或重置位姿冒充制动。原生位姿只用于独立审计，不交给导航控制器。
4. 观察到非零速度后，独立观察者收到零速，原生位姿速度降到原静止门槛以下。
   恢复/收尾的独立执行日志保持锁存；故障运行全部completed=false。

| 声明故障 | 独立发布相对原租约到期 | 故障钩子至独立零速 | 外部物理最终线/角速度 | 运行器末次清理stationary |
|---|---:|---:|---|---|
| 助手SIGSTOP | 约+0.320ms | 约0.796s | 0 / 0 | false |
| 导航进程SIGSTOP | 约+0.317ms | 约0.795s | 0 / 0 | true |
| 管道断开 | 未等原租约到期 | 约0.182ms | 0 / 0 | false |

独立命令观察者收到零速的时间另存原始工件；这里不是仅依据执行进程自报。
每例实际观测最大线速度约0.150m/s、最终0，最终角速度0，未放宽0.01m/s/0.02rad/s静止判据。
助手故障时主流程仍在30秒后才处理异常，但独立零速与外部物理停稳早已发生。
管道断开例主进程`zero_command_submitted=false`如实保留；独立执行端/外部观察者的零速是另一份证据。
助手/断管例不满足运行器最后清理区间位姿要求，因此仍stationary=false，不拿外部测试结果回填原审计。

这些是声明故障注入与有界工程诊断，不是自然故障率、全工况制动距离或正式S2/S6实验。
测试的调度/消息观察容差单独列在脚本中，不改变生产0.8秒到期判定，也不保证每次系统负载下均为上述毫秒值。

## 仍存在的边界

- 保障依赖独立执行进程、原生发布通道和OS调度健康；执行进程自身被SIGSTOP/SIGKILL、OS整体挂死、
  原生发布调用永久阻塞或电机链路故障，不在本批保证内。不能以软件子进程代替底盘/驱动器侧硬件租约。
- 非硬实时系统只能实测调度延迟，不能保证零速严格在0.800000秒以内送达；更不能保证物理制动在0.8秒内完成。
- 每次发布调用与真正接收/制动仍是不同事实；接触覆盖未补齐，保持collision_free_certified=false。
- 不新增真实硬件驱动，不改现有ROS2部署轨道。实车仍需在底盘固件/驱动器接收端实现并验收独立超时制动。
