# 直行增量：参考候选搜索准备复用

2026-11-03（Asia/Shanghai）。本轮只减少重复计算，不改变直行策略或安全门槛。

`free_ground_path.reference_cell_candidates` 在同一次九格×九候选调用内，
复用 `PreparedAlternative` 的 float32 参考画布、整数坐标与支持掩码腐蚀。
首个可用补丁才建立上下文；全平坦或全无支持图不做搜索准备。
上下文不存入控制器、不跨帧，也不出现在证据对象中。

每个有效候选依然独立提取补丁、测量自 NCC、执行完整画布的模板匹配，
按原排除圆/支持掩码/非有限过滤取最大值与计数。不缓存或省略匹配分数。
81 个有效候选依然是 81 次实际匹配，但支持腐蚀由 81 次减到 1 次。
四个逻辑搜索计数、失败原因、稳定选点顺序及所有门槛不变。
目标帧九格的双向/自重复检查与整流否决不改。

`reference_appearance_evidence` 保留原三参数默认路径，新增私有 `_search`
钩子，仅供该批候选提供同图同掩码的搜索。S1 描述子、控制器、速度、
停车、恢复、0.8s 租约和 0.4s 审计期限均未修改；默认仍 `no_motion`。
已存在的显式实验也使用这项计算去重，不等于推广那些实验策略。
