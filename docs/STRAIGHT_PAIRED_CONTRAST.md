# 成对原生补丁：精确对比度快速判定

2026-11-04：已保留默认接入。只优化原`std>=2`布尔判定，不改变描述子政策。

## 数值等价边界

[native_patch_contrast.py](/home/sunrise/toponav_project/roadvision/native_patch_contrast.py)
保留原端点检查、`getRectSubPix`及float32补丁。仅原生128×128 uint8画布、
原11×11提取函数进入专用路径。121个整数像素的精确方差为：

`V = (121*sum(x*x) - sum(x)**2) / 121**2`。

`cv2.integral2`以int32和float64生成整数和/平方和，所有整数均精确可表示。
若`V<1`直接拒绝，若`V>9`直接接受，其余**仍调用原float32标准差并与2比较**。
这些是充分条件，不是把标准差阈值改成1或3。

原float32方差相对精确方差的保守绝对误差小于0.27：均值和减法舍入使每个
平方项误差<0.00974，最多120次非负求和舍入合计≤30，除法误差≤2^-9；
总界为`0.00974+30/121+2^-9 < 0.27`。因此上述远区判定不可能跨越原阈值，
最终sqrt舍入也不能跨越余量。近阈值结果完全沿用原计算。

H/I源文件保持原字节。新模块分别保留两套原证据逻辑，测试通过AST规范化
确认只替换补丁读取；原回调被替换或画布/政策不适配时尊重原函数。
**没有补丁/NCC缓存、接受结果合并、少做NCC或缩小完整模板搜索。**
每个补丁临时生成两个12×12积分数组，共1728字节，不持久缓存，也不是零分配。
