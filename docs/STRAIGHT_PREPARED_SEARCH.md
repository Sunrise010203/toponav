# 普通直走：区域内描述子搜索准备复用

2026-11-01。只优化重复计算，不更换描述子、接受集合或控制策略。S2未通过、S6未完成；默认仍为`no_motion`。

## 实现边界

每次S2/历史区域过滤已确定两张局部画布后，各建立一个`PreparedAlternative`，一次性转换原float32目标图、生成原整数分数坐标，并按原11×11足迹腐蚀支持掩码。同一条轨迹的两个预期端点各生成一次原半径11px排除范围，供该端点对应的两次搜索复用。

**仍然完整执行四次`cv2.matchTemplate(..., TM_CCOEFF_NORMED)`**：正向、反向和两张图的自重复。既不缓存匹配分数，也不缩小有效搜索范围、不重选点、不跳过任何失败检查。原NCC、margin、自重复、非有限分数过滤、有效位置计数及其余证据原样返回。插值支持、整流自重复否决、训练/留出分配和拟合保持不变。

上下文只存活于一次区域调用，不保存在控制器、历史帧或输出中；不读取场景标签、仿真位置、地图、物理或深度信息。输入画布由当前调用生成且不修改，随后立即丢弃。

## 默认S1与S2选择

本轮**确实修改了共享S1源码**`rgb_motion_checks.py`和`rgb_resampling_checks.py`，增加私有可选准备路径；不再声称这两个文件字节冻结。原独立搜索函数和其他模型/门槛不改，默认S1入口仍走原未准备路径。

新`prepared_descriptor_checks.py`通过原两参数接口供`ground_history.py`及`straight_history_support.py`选择准备路径；不新增控制变体，不做通过/失败后的OR或回退。默认普通直走及历史实验经这些S2生产者取得等价加速；独立S1探针不自动切换。源码差异与逐函数边界审计、精确相等测试和回放结果必须同时保留。
