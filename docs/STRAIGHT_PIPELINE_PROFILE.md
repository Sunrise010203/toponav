# 当前直走链路的只读剖析

`tools/straight_pipeline_profile.py` 是离线诊断工具，生产链路不导入它。
它读取冻结的公共任务、顺序清单、RGB和保存决策；不读取 `result.json`、
模拟器物理/几何审计或场景标签。任务声明决定变体、净空先验和运动许可，
保存决策只用于调用结束后的完整等价性核对，不供控制器选点或决策。
不会连接执行器。默认禁止运动的生产契约不变。

## 三种数据不能混用

1. **普通计时**：图像已解码，计时仅包围 `update`（或显式的missing/cancel）。
   使用新控制器完整顺序执行；没有阶段钩子或cProfile。完整输出比较及JSON
   写入在计时之外。记录wall和整个进程的CPU，CPU可因多线程BLAS大于wall。
2. **阶段剖析**：另跑一次完整序列，显式包装选定调用。按函数身份收集已加载
   roadvision模块/类中的别名，并包装匹配、LK和透视重采样的OpenCV入口。
   保留原调用/返回/异常，退出后还原全部引用；仅在当前同步线程的测量内记账。
   模块在装钩前预加载，不能保证捕获测量中临时导入的未知别名。
3. **cProfile**：再独立执行一次，输出原始 `.prof`、self/cumulative文本和含
   调用方的完整JSON。比较结果在profiler关闭后进行。

阶段/cProfile有仪器开销，**不能把它们的耗时当普通计时，也不能和旧轮报告
的绝对耗时直接比较来宣称提速**。本工具测当前实现，不提供前后版本性能准入。

## 阶段归因

涵盖启动纹理、静止运动、导航历史/几何、历史准备、地面证据、ROI跟踪、
H/I配对、地面/走廊/前表面拟合、区域模型、非线性求解、模板匹配、LK、
透视重采样、通行与指令计算。内外层可以嵌套：

- `inclusive` 含所有子阶段，**不能跨标签相加计算份额**。
- `exclusive` 扣除所有已计时子调用，包括同标签递归。
- 一次调用全部exclusive之和加`uncovered`等于其整体仪器耗时。
- exclusive/uncovered也含部分记账成本，不等于函数纯算法self耗时。
- 只保留当前调用的分阶段汇总及嵌套栈，不生成逐函数事件历史，不缓存图像
  或描述子评分。逐决策记录只写入显式指定的新输出目录。

## 输出与复用

每轮必须先冻结当前源码、计划、工具/测试和输入，再运行。例如本轮：

```bash
cd /home/sunrise/toponav_project
.venv/bin/python tools/straight_pipeline_profile.py \
  --plan /home/sunrise/toponav_project/reports/straight-followup-20261101-09/PLAN.json \
  --freeze /home/sunrise/toponav_project/reports/straight-followup-20261101-09/MEASUREMENT_FREEZE.json \
  --output /home/sunrise/toponav_project/reports/straight-followup-20261101-09/profile
```

已存在的输出目录会拒绝覆盖；复用要选择新目录，而且不能将新源码执行误称
原冻结测量。冻结或像素不匹配、公开路径逃逸、任务附带未知字段、决策不一致
均失败；部分日志保留，失败不产生成功SUMMARY。OpenCV线程数在结束/异常时
还原，BLAS及生产参数不调优。测试、测量、回放与物理运行不能并行。

普通延迟统计提供明确分母：完整序列、非零指令调用及每种进入状态；包含
p50/p90/p95/p99、最大值、均值和超过0.1秒的次数/比例，不删慢样本。
重复同一输入的样本相关，少量重复的p99不是部署SLA，也不证明泛化。
阶段占比、原始调用树及各轮统计需结合查看后才选择下一处优化。

## 本任务的边界

本轮仅做优化后诊断，不修改任何既有生产/测试/配置文件，不推广实验策略。
基线、`wide_reference`和`gradient_transfer`分开列结果，后两者仍未获策略推广。
它不测采集、解码、传输、指令接收或真实停车延迟，不解决IPC超时、近场盲区
或0.25m窄障碍覆盖，不把仿真暂停计算当真机实时证明。
普通已暴露四条件仍0/4完成；0.1s预算、S2与S6未获得新的验收结论。

最终实测、软件回归、下一优化点及证据完整性见本轮 `REPORT.md`。
