## 1. 已核实的第三分块契约

权威来源：`/home/sunrise/toponav_project/simulation/structural_localization.py`、`simulation/structural_navigation.py`、`docs/NAVIGATION.md`。

第三分块只接收：

```json
{
  "relative_open": {"front": true, "left": false, "right": false, "back": null},
  "confidence": 0.5
}
```

- 顶层只能有 `relative_open` 和 `confidence`；不得塞入类别概率、时间戳或真值字段。
- 四方向键必须齐全，值为布尔值或 null。null 是未知，不能当作 false。
- confidence 低于 0.6 不用于排除候选；即使置信度高，观测不完整也停止。
- 观测相对于拍摄时的小车朝向，不是地图的东/西/南/北。
- 图像不提供节点身份、真实朝向、坐标、地图边 ID 或目标到达结论。

## 2. 相机与类别选择

建议第一版使用同一模拟时刻、同一位置的四个 RGB 视图，固定面板排列：左上 front、右上 left、左下 right、右下 back。四个视图面向相差 90 度的相对方向；面板不绘制方向文字、节点 ID、坐标或地图。

先进行可见性检查：相机视场与画面必须足以支持该方向结构的判断；不能因为具有四个相机就默认任意遮挡都已排除。四视图是采集方案，不能把前视一张图片复制四次冒充四向观测。

选择依据：

- 推荐四向视图 + 出口组合分类：直接对应当前完整观测契约，模型仍是一个 MobileNetV3-Small。
- 仅用前视 + back=null：安全但第三分块会停止，不能宣称完成高成功率闭环。
- 四方向各自分类：可表达局部未知，但增加输出头和融合规则，第一版不采用。

### 固定 17 类

前 16 类表示四个方向的完整可见出口组合，最后一类表示无法完整判断。方向位顺序严格为 front/left/right/back，1=开放，0=明确不开放。

| 索引 | class_id | 相对出口 | 结构说明 |
|---:|---|---|---|
| 0 | exits_0000 | 无 | 全部封闭；不是通常意义上的单出口尽头 |
| 1 | exits_0001 | 后 | 面向尽头 |
| 2 | exits_0010 | 右 | 单出口在右 |
| 3 | exits_0011 | 右、后 | 右侧转角 |
| 4 | exits_0100 | 左 | 单出口在左 |
| 5 | exits_0101 | 左、后 | 左侧转角 |
| 6 | exits_0110 | 左、右 | 横向直通 |
| 7 | exits_0111 | 左、右、后 | 前方封闭的 T 形结构 |
| 8 | exits_1000 | 前 | 单出口在前 |
| 9 | exits_1001 | 前、后 | 纵向直通 |
| 10 | exits_1010 | 前、右 | 前右转角 |
| 11 | exits_1011 | 前、右、后 | 右支路 T 形结构 |
| 12 | exits_1100 | 前、左 | 前左转角 |
| 13 | exits_1101 | 前、左、后 | 左支路 T 形结构 |
| 14 | exits_1110 | 前、左、右 | 后方封闭的 T 形结构 |
| 15 | exits_1111 | 前、左、右、后 | 十字结构 |
| 16 | unobservable | 无法完整判定 | 过渡、遮挡、缺视图或相对方向无法可靠对齐 |

0..15 可看作四位二进制编号，只编码相对结构，不编码节点。地图从 4 个节点换成 6、7 或更多节点，输出仍是 17 维。节点改名不改变标签。不能用一个不带方向的 `t_junction` 直接填充四个 relative_open 值。

17 类是模型接口的固定类别全集，不保证当前六节点场景包含每一类。训练、验证、测试各类支持数必须公开；没有数据的类别不得宣称已验证可识别。

## 3. 标注规则及边界

### 正式可分类图像

- 对象是当前模拟观测站位附近、四视图能够共同支持的道路出口结构，不是远处即将到达的路口。
- 第三分块是原子转向并走完整条通道的离散模型。可信控制观测在动作前或执行明确完成后、位置与朝向稳定时采集。
- 采集规范须固定观测站位区域、朝向容差及视场；这些物理标注条件由模拟器用于数据生成，不向模型提供位置/朝向真值。
- 开放标签由独立物理场景及可见封堵状态确定。标注为关闭的通道要有相应可见墙体/封堵；不能只是修改地图 enabled 字段，而画面仍显示开放。
- 开放结构不等于通道具有足够宽度、可安全行驶或具备完整实车通行授权。

### 接近、通过、转向和不完整视野

| 状态 | 标注/接口处理 |
|---|---|
| 接近路口，出口仍被墙角遮挡或尚未进入定义的观测站位 | unobservable；不提前用前方路口类别推进候选 |
| 到达稳定观测站位，四方向均可判断 | 按当时相对出口组合标注 |
| 通过/离开路口，旧出口已经滑出视野或结构参考点不明确 | unobservable；不沿用上一帧完整结构 |
| 转向中、非确认的基准朝向或视图不同步 | unobservable；转向结束后按新朝向重新采集与标注 |
| 完成转向但尚在通道移动中 | 不作为已完成一个节点转移的观测；训练过渡样本标 unobservable |
| 缺相机图像、遮挡、曝光失败、画面不完整，任一方向不能判断 | unobservable；不会把未看见的出口标 false |
| 单出口在后方 | exits_0001，不是“已到目标”；目标到达由第三分块处理 |

过渡状态只供标注和审计。模型只能看到 RGB 图像，不能读取阶段、节点或真实位姿后直接输出正确类别。unknown 类及软最大分数也不能保证检测所有分布外样本，须实测拒识和错误接受。

## 4. 正式模拟数据（在第四分块内完成）

不再要求先完成第六分块。直接为当前任务补充最小的可渲染模拟场景和四向采集流程；不把无相机的结构概率传感器冒充图像采集。

- 使用多个确实不同的道路连接布局，而不是只改节点编号、显示坐标或纹理就宣称跨布局泛化。
- 第一版至少有两个训练布局、一个独立验证布局、一个封存最终测试布局。节点数可以变化，标签全集固定。
- 每个布局采集多个完整批次，覆盖站位、朝向、材质、光照、可见封堵和上述过渡/遮挡样本。
- 每样本记录 layout_id、batch_id、frame_id、采集时间、四相机配置及标签；位置/朝向和节点如为审计保留，放在真值元数据中，训练输入仅为图像。
- 先锁定 layout→split 清单；整批次与近邻帧保持同一分组。训练/验证/最终测试布局互斥，布局拓扑指纹也要检查，防止节点改名后的同布局泄漏。
- 最终测试布局不参与训练、超参数、类别规则的数据驱动修改、校准或拒识阈值选择。模型/阈值冻结后再打开测试评估。
- 禁止把随机张量、噪声图片、烟测 PNG、节点文字地图或按标签拼出的概率作为正式数据。
- 不进行没有标签重映射的左右翻转、相机排列变更、旋转或裁剪。归一化采用预训练模型参数，缩放完整四视图面板，不裁掉某个方向视图。

当前 data_raw/data_processed/models 仍空，预训练 MobileNet 尚未获取。只有采集清单、标签检查、分组隔离和类支持数检查通过后才能启动训练。

## 5. 训练、输出及低可信度

- 本机既有 GPU 环境训练，使用 torchvision 官方 MobileNetV3-Small 预训练权重，替换分类输出为 17 类。
- 冻结 features 骨干参数及 BatchNorm 运行统计，只训练 classifier；保存权重、类别顺序、采集规范和预处理配置。不能只冻结梯度却继续更新骨干 BatchNorm。
- 验证集确有证据表明冻结方案不足，才另存微调实验。旧节点权重若存在，不覆盖；原模拟器和节点概率基线也不覆盖。
- 模型结果单独输出 class_id、固定顺序 class_ids/probabilities、frame_id、采集/推理时间、耗时和拒识原因。计时采用明确的时钟域，不混用离线录像时间与当前墙钟计算新鲜度。
- 传给第三分块的适配结果只含 relative_open/confidence。类别概率及时间信息保留在旁路结果/日志，不增加第三分块观测字段。
- 验证集选择拒识阈值 τ，且 τ≥第三分块已有的 0.6。输出未知类、低于 τ、缺视图、视图不同步或已过期时，返回四方向 null、confidence=0，并记录原因。
- 接受已知类别时，按四位标签生成布尔 relative_open，confidence 使用该类别分数。Softmax 分数不是已证明校准的真实可信概率。
- 若以后使用只有前视的输入，未观测到的后方必须是 null，不从地图、默认值或上轮真值补齐；当前第三分块因此停止是正确安全行为。

## 6. 独立验收

1. 输出维度及类别顺序不随地图节点数量改变；4/6/7 节点和节点改名均有测试。
2. 第三分块严格字段校验通过；低可信度、unknown、缺失/过期图像导致明确停止，不排除候选或泄漏真值。
3. 测试集输出完整 17 类混淆矩阵、各类支持数及准确率；另外报告已知结构准确率、拒识覆盖率、被拒数量和错误接受情况，不只统计容易被接受的样本。
4. 目标设备 batch=1、预热后测模型前向及含预处理的推理延迟，报告平均/P50/P95及硬件线程配置；模型加载单独计时。
5. 实际图像驱动闭环需独立报告到达成功率、错误动作和安全停止，并保持控制器结果与真值审计分离。分类准确率不等于导航成功率。
6. 旧基线源文件/模型哈希保持不变；原回归测试继续通过。

结构识别不输出通道宽度、距离、精确角度、连续位姿、几何估计或完整控制。本文未训练模型、未报告任何虚构的视觉准确率。
