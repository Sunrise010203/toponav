# 最小导航闭环设计

目标：在 `/home/sunrise/toponav_project` 的 Python 3.10 环境中，用模拟节点概率替代摄像头，连接识别、定位、Dijkstra 规划、决策和二维环境。

采用离散节点级仿真：一个方向动作沿一条真实通道移动到相邻节点，更新二维坐标、朝向、累计路程。不是连续动力学、ROS 通信或实车控制。现有六节点地图和 Dijkstra 保持不变。

数据流：环境当前节点 → 模拟识别概率 → 最大概率定位（低置信度停止）→ 从定位节点重新规划 → 取路线第一个方向动作 → 环境按真实位置执行 → 再次从更新后的环境生成概率。

识别默认 one-hot 理想观测；可使用指定置信度，其余概率均分给其他节点。定位和决策接口不接收环境真值；真值仅由识别模拟器、动作执行器和日志/验收读取。动作只有 east/north/west/south，不携带目标节点，不可通过规划结果直接修改位置。

环境根据 scene.json 物理通道和 graph.json 的 enabled 状态、临时关闭通道检查移动；不允许穿墙或越过关闭通道。不可达、低置信度、动作受阻、步数耗尽均有明确停止状态。到达后保留最终新位置的观测，停止动作不改变坐标。

验收：正常 N01→N02→N03→N04→N06，4 次动作、8 米、终点 (6,2)；C02 关闭时经 N05 绕行；C06 关闭时不可达。测试逐步核对观测概率对应当前位置、动作前后坐标不同、下一轮观测来自动作后位置。全六节点起终点组合及通道关闭子集与现有规划器结果对照。

输出：可重放的 JSON 步骤日志、二维真实轨迹 PNG、独立运行说明和测试结果。无需安装软件或修改 SSH/系统配置。
