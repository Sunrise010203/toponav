# 场景与拓扑地图 v2 已确认设计

日期：2026-10-14。用户已确认前一轮字段修改方案。

保留现有六节点、六边、各 enabled 状态、坐标与尺寸；不安装环境，不新增导航业务源码。通用 schema 取消固定示例 ID、节点/边数量、逐节点允许连接与几何常量；格式版本 2.0、四方向正交和双向简单图协议仍保留。

graph.nodes 保存结构 node_type、neighbors 和明确绑定的 exits；N06 从 goal 改为 dead_end。graph.task 是可选的任务起终点和起始朝向，不要求通过图像识别目标角色。scene.channels 是每地图独立确认的物理连接和端点出口方向事实；scene.geometry 可选，供模拟器显示、标注和评价，不能作为视觉识别输入。reference_images 可选，无逐点照片要求。

地图 x 向东/y 向北，出口为当前节点向外方向；east=0/north=90/west=180/south=270，逆时针为正。按当前节点向来路的出口方向加 180 得到进入朝向，再得到相对出口；来路未知不得猜测。显示坐标不决定出口语义。通道关闭不改变物理拓扑，启用边可达性与非法连接分开报告。
