# Dijkstra Path Planning Implementation Plan

> **For Claude:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** Compute a shortest enabled-channel route and replan after closures, or report unreachable, in the Ubuntu VM.

**Architecture:** A standalone Python module reads the existing graph and builds adjacency from enabled edges. Heap-based Dijkstra reconstructs node and channel sequences; each invocation uses current channel availability without modifying the graph.

**Tech Stack:** Python 3.10 standard library and the existing pytest environment.

### Task 2: Minimal implementation

**Create:** `simulation/dijkstra.py`.

1. Provide `plan(graph, start=None, goal=None, disabled_channels=())`; validate node/channel identities, endpoints, finite nonnegative weights and explicit Boolean availability/direction flags.
2. Build adjacency from edges with `enabled` true and channel IDs absent from the disabled set; add reverse adjacency only for bidirectional channels.
3. Initialize `distances[start] = 0.0` and heap `[(0.0, start)]`; skip stale entries, relax only strict improvements, and store predecessor node/channel. Reconstruct on reaching the goal. Exhaustion returns unreachable with empty routes and null distance.
4. CLI: `--map`, `--start`, `--goal`, `--disable C02 C05`. Print JSON; reachable/unreachable/invalid exits 0/1/2.
5. Run the same pytest command. Expected: all pass, including exhaustive oracle comparison.
