## 4. 统一指标口径（7A 中冻结具体阈值）

| 指标 | 必须使用的定义/限制 |
| --- | --- |
| 导航成功率 | 预算内真实到达且满足预声明安全条件的任务数 / 全部预定义可达导航任务；预算、到达区域及朝向条件预先锁定 |
| 误到达率 | 宣称到达但审计未到达的任务数 / 全部任务；另报其占全部“宣称到达”的比例 |
| 已知结构准确率 | 正确分类的已知样本 / 全部有效已知样本；另报输入无效数与逐类支持数 |
| unknown 错误接受率 | 被当作可信已知结构接受的 unknown 样本 / 全部预定义 unknown 样本 |
| 接受覆盖率 | 被接受观测 / 全部应处理观测；已接受准确率另列，不能与总体准确率混用 |
| 定位表现 | 歧义帧、错误唯一确认分别计数；真值仅事后审计，不用于决策修正 |
| 恢复成功率 | 预算内恢复正确可靠状态的事件数 / 全部预定义恢复事件；未检测到、超时和失败都保留 |
| 恢复耗时 | 故障开始至正确恢复，以及故障检测至正确恢复分别报告；失败计数与删失规则预声明 |
| 路径代价比 | 成功路线 hops / 相同可通行条件下最优 hops；零距离/不可达单列，同时报告成功率，不能只看成功子集效率 |
| 米制行程 | 仅有物理/几何审计依据时报告；无依据为 null，不能把一条边当一米 |
| 碰撞任务率 | 有接触/碰撞的任务数 / 全部已执行任务；另报未执行数及接触判定，不能按帧稀释 |
| 制动 | 从每次停车请求到满足预声明持续停稳条件的时间与距离；最终停稳与逐次制动分开，恢复命令不得抹去未完成停车 |
| 时延 | 纯前向、预处理+推理、端到端链路各报 median/P95、样本数、设备/线程；仿真秒与墙钟秒分开 |
