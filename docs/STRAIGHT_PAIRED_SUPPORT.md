# 原生 I 支持掩码准备：独立实验，未默认接入

候选仅将同一私有区域内不变的支持掩码惰性转换为 float32 一次；每次有效补丁仍
执行原 `getRectSubPix` 和 `>=1.-1e-6`，不缓存补丁/NCC，不改变匹配、支持侵蚀、
有限值检查、总体、H/I接受、模型或相机/标定。原生掩码来自同次画布准备，调用期间
由该区域拥有且不修改，和既有已准备目标画布一样不跨区域/帧保留。

`PreparedSupportMask` 仅保存该静态源及最多一个 float32 采样画布，首次真正需要
支持采样时才转换。非适配输入保持原对象，自定义证据/支持回调收到原始掩码。
两个掩码最多额外保留 131072 字节 float32 数据；不是零分配或全程无内存成本。

完整比较的默认序列总 wall 中位/均值分别退化约 0.89%/3.03%，不满足三例全部严格
改善门槛。两个生产文件已恢复原字节。新 helper 保留为**独立实验模块**，默认配对
和对比度模块不导入它。测试显式加载归档候选及其配套 helper，并另断言默认文件
仍为 before 原字节；不是默认接入的证据。未重测性能、未执行条件回放。
