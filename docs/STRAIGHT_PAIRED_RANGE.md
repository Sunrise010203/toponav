# 原生补丁灰度跨度判定：独立实验，未接入默认

2026-11-04。`roadvision/native_patch_range.py` 仅用于保留可复核的实验，
默认配对/对比度模块不导入它。完整序列性能门槛失败，生产及临时测试改动均已恢复。

## 精确充分条件

仅适用 exact ndarray、uint8、11×11。令 N=121，灰度跨度 R=max-min，
总体方差 V。两个极值相对均值的平方偏差之和至少为 R²/2，故
V≥R²/(2N)；另有 V≤R²/4。

- R≥47 时 V≥2209/242>9，进入既有整数矩证明的远接受区。
- R≤1 时 V≤1/4<1，进入既有远拒绝区。
- 其他跨度不作决定，继续原积分矩及原 float32 std 边界路径。

这不是更改 std≥2 阈值，也没有改变补丁提取、NCC、支持采样、实际匹配次数、
证据检查或控制预算。整数极值由 cv2.minMaxLoc 获取；节省积分次数不等于实测提速。

## 结果与测试范围

唯一一次固定串行完整比较全部输出精确，但默认序列总wall中位/均值退化
6.402%/2.914%，正横偏退化1.442%/0.738%，不接入。没有追加候选计时、剖析或条件回放。

新增24项测试从一开始就显式加载归档候选，对全uint8跨度、布局、充分/模糊区、
不适配输入进行精确检查。它们验证独立实验，不代表默认启用。之前的支持掩码测试
曾临时缩小字节锁定范围以容许本轮实验，性能失败后也恢复原字节；没有永久削弱旧断言。
