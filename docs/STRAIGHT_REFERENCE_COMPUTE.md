# 普通直走：参考补丁的等价计算去重

2026-11-01。承接固定梯度实验，先减少重复计算，不再改变描述子接受集合。S2未通过、S6未完成；不调整授权、速度、制动、恢复预算、模型、传感器或标定。

## 修改

`reference_cell_candidates()`的每个参考候选，原来调用
`appearance_evidence(image,image,point,point,mask,mask)`。同一图、点和掩码使两个端点补丁及四个全画布竞争搜索分别完全相同。

新增`roadvision/reference_patch_evidence.py`，只在S2参考选点处执行一次补丁提取、一次原始全画布竞争搜索。仍调用原`_ncc(patch,patch)`测量观测分数，**不假设或强设NCC=1**。NCC≥0.70、margin≥0.06、自重复<0.94及原掩码/边界/平坦/无竞争位置处理保持不变；输出所有分数、原因和四个逻辑搜索的有效位置计数不变。没有跨调用缓存，不复用旧帧，不根据目标帧筛选或重试。

保留原九格×九候选的顺序及稳定选点；九格目标图检查依然调用原双向/自重复实现，梯度、光流、往返和所有几何门槛均不变。默认及各显式实验经同一个参考采样函数获得等价加速，不新增控制变体、不推广实验。共享S1描述子文件及控制器均未改动。

## 验证边界

性能剖析在已暴露、哈希核对过的公共RGB上执行，不用仿真真值。参考选点仅是部分耗时；主要描述子跟踪工作仍保留原计算。交替顺序、相同输入、预热后比较备份的旧实现与最终候选；必须把局部节省和完整控制决策耗时区分，不能把同步仿真采集时钟当硬实时。

新单测逐字段核对参考证据、81候选及九个选点、完整灰度/梯度证据包；覆盖分数门槛邻点、分数缺失、平坦/重复、浮点/亚像素点、边界、填充及无可用竞争位置。计算次数测试不使用易抖动的墙钟时限。另以原公共录制逐决策回放检查控制输出、证据、终态及权限保持一致。

最近两轮57组旧录制严格回放一致；更早六变体录制在优化前即存在启动纹理证据字段不兼容。本轮对其135条输入作优化前后整包重算，结果一致，但不算六组旧录制回放通过。

本轮未新增专门的物理对照或验收套件；软件测试包含既有短仿真，不把它们计为新物理验收。旧物理审计只是历史结果；等价回放不提高原普通条件的完成率，也不修复窄障碍视觉停车覆盖和完整近场盲区。详细数据及全量测试结果见[本轮报告](/home/sunrise/toponav_project/reports/straight-followup-20261101-04/REPORT.md)。
